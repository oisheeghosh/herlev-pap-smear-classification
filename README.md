# Herlev Pap Smear Image Classification

Machine learning classification of cervical cell images using the Herlev Pap smear dataset.

## Overview

This repository contains a machine learning workflow for analyzing and classifying cervical cell images from the Herlev Pap smear dataset. The project explores image-based classification as part of a broader research interest in machine learning, medical imaging, and computer-aided cervical cancer screening.

## Dataset

The project uses the **Herlev Pap Smear dataset**, which contains cervical cell images representing different cellular categories.

> The dataset is not redistributed in this repository. Please obtain the dataset from its appropriate original/source repository or publication.

## Objective

The objective of this project is to investigate machine learning approaches for classifying cervical cell images and to evaluate their performance using appropriate classification metrics.

## Workflow

The notebook includes the following stages, where applicable:

1. Dataset preparation
2. Image preprocessing
3. Feature preparation/extraction
4. Model training
5. Model evaluation
6. Performance comparison

## Evaluation

Model performance is evaluated using metrics available in the notebook, such as:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion matrix

Results reported here correspond to the experimental setup implemented in the notebook.
